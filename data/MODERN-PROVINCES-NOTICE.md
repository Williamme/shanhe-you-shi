# Modern province boundary data

`modern-provinces.geojson` was downloaded from DataV GeoAtlas:

- https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json

It is used only as an optional modern geographic reference layer on the
historical map. Use of this dataset is subject to the DataV GeoAtlas terms.
The modern boundaries are not presented as historical borders.
